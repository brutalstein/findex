# Findex validation

Reproducible, Windows-first evidence for Findex's correctness, retrieval
quality, performance, security and Claude Code integration. Every number in
`FINAL_VALIDATION_REPORT.md` comes from a run directory under `results/`.

## Layout

| Path | Contents |
|---|---|
| `requirements.md` | What must be installed; what each component needs (network, Claude login, privileges) |
| `methodology.md` | How each measurement is taken, controlled and scored |
| `acceptance-criteria.md` | The ten release gates and their thresholds |
| `test-matrix.md` | Which test covers which risk, and where its evidence lands |
| `golden/` | Golden retrieval dataset (`symbol_navigation.jsonl`), generated by `harness/golden.py` |
| `harness/` | Python harness (stdlib + `psutil`) driving the real `findex.exe` and the official `claude` CLI |
| `scripts/` | PowerShell entry points (`run-*.ps1`, `generate-report.ps1`) |
| `results/<UTC>-<sha12>/` | One run: `manifest.json`, `environment.json`, `commands.jsonl`, component JSON, `summary.md`, `checksums.sha256` |
| `fixtures/`, `datasets/`, `benchmarks/`, `reports/` | Reserved; fixtures are generated on the fly by the harness |

## Quick start (Windows 10/11, PowerShell)

```powershell
py -3.12 -m pip install psutil
.\validation\scripts\run-all.ps1 -Quick -Offline      # no network, no model usage
.\validation\scripts\run-all.ps1 -TotalBudgetUsd 6    # full run incl. real Claude Code sessions
```

`run-all.ps1` first runs `harness/corpora.py`, which clones the pinned corpora
into `%LOCALAPPDATA%\findex-validation\corpora` and builds the frozen baseline
binary (commit `44f1a38`). With `-Offline` it only verifies them.

Single components: `run-unit.ps1`, `run-retrieval.ps1`, `run-performance.ps1`,
`run-security.ps1`, `run-integration.ps1`, `run-claude-ab.ps1`. Pass the same
`-OutDir` to collect several components in one run directory, then
`generate-report.ps1 -OutDir <dir>`.

Flags: `-Quick` / `-Extended` (scope), `-Offline` (records Claude components as
BLOCKED), `-OutDir`, `-Priority BelowNormal|Idle` (resource limit for
performance runs), `-SessionBudgetUsd` / `-TotalBudgetUsd` (spending limits for
real model usage).

## Status vocabulary

`PASS`, `FAIL`, `SKIPPED` (precondition missing, with reason), `BLOCKED`
(external dependency unavailable or not authorized), `NOT_RUN` (component not
executed in this run). Only `PASS` counts as passing.

## What is committed, what stays local

Committed: sanitized JSON/Markdown results (private paths replaced by
`%LOCALAPPDATA%`, `%USERPROFILE%`, `%REPO%`), checksums, harness, golden data.
Local only (gitignored): `results/*/raw/` per-query dumps, Claude stream-json
transcripts, corpora, isolated Findex state, build output. Credentials are
never read: the harness only asks `claude auth status` whether a login exists.
