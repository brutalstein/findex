# Findex

Native Windows code intelligence for the official Claude Code CLI.

> Experimental v0.1 foundation. Not production-ready; no verified token-savings claims.

Findex is a local-first Rust workspace with a Windows terminal launcher, a SQLite FTS5 lexical index, and a Claude Code MCP plugin. See the upcoming source and CI commits for build instructions and architecture.

Findex is an independent project, not affiliated with Anthropic.
