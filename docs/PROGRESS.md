## What each round changed

- **R0** (2026-10-27): Baseline. Three-tool definition comparison, first localization measurement on the 65 reused issues, and the two-task Codex navigation pilot.
- **R1** (2026-10-28): First context-ranking iteration; localization re-measured. Two-task Codex bugfix pilot: Findex had one 300-second timeout.
- **R2** (2026-10-29): Locality ranking iteration (conceptual vs exact split, filename words, nearby evidence). Bugfix pilot repeated: all tools solve both tasks, codebase-memory uses fewer tokens than Findex.
- **R3** (2026-10-30): No ranking change since R2. Re-measured on HEAD to confirm the numbers; the live harness was repaired the same day (invalid sessions no longer halt a study; single-definition tasks; answer parsing).
- **R4** (2026-10-30): First Claude Code live round on HEAD with the repaired harness: four single-definition tasks, three tools, Claude Haiku via subscription. Every session spent a tool-search turn; the harness prompt steered Findex to its deferred tools.
- **R5** (2026-10-30): BM25 scores serialized to three decimals (about 8% fewer Findex tokens per query, same hits). Harness hint now points Findex sessions at the upfront findex_context tool, so they skip the tool-search turn. Same four tasks as R4.
- **R6** (2026-10-30): No Findex change since R5. Four fresh tasks (ripgrep, fmt, two requests) to check that the R5 result holds beyond the tasks the hint was written against; the rivals had more invalid sessions.
- **R7** (2026-10-30): Concept ranking demotes vendored copies (factor 0.5) and docs, examples and support scripts (0.7) on the BM25 score. Five tasks moved up, none down.
- **R8** (2026-10-30): Concept ranking relaxes FTS5's fixed BM25 length normalisation (b 0.75 to 0.3, set in advance, not fitted) so large central files are no longer penalised. Dev and test both improve; 19 tasks moved up, 5 down (none beyond rank 13).
- **R9** (2026-10-30): Concept ranking adds a symbol-name field: the share of query words that name a definition in the file. Chosen on dev (one candidate; a proximity feature was tried and dropped), confirmed once on the held-out half. First round with Graphify and codebase-memory measured offline on the same 65 tasks.
- **R10** (2026-10-30): First live issue-localization study: 8 held-out issues, four arms (Findex, Graphify, codebase-memory, no tool), Claude Haiku via subscription, 20-turn cap. Findex ties codebase-memory at 4/8 with the fewest tokens, but three Findex sessions ran out of turns although offline Findex ranks the right file first on 7 of the 8 issues.
- **R11** (2026-10-30): Concept output now opens with a `ranked files, most likely first` line. Findex-only re-run on the same 8 issues: 6/8 correct (was 4/8), 7/8 valid (was 5/8), 143k tokens per session (was 420k). The change was designed after seeing the R10 failures on these issues, so this is not an independent test; rivals were not re-run.
- **R12** (2026-10-30): Codex subscription reopened after the usage limit that blocked the earlier luna pilot. Four fresh single-definition tasks (ripgrep x2, fmt, requests), gpt-5.6-luna at low effort, three tools, one repetition. Findex 4/4 correct; Graphify 3/4; codebase-memory 3/4 valid and correct 3/4.
